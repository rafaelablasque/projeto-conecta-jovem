SOBRE O PROJETO

Ideias que conectam

O ConectaJovem é uma plataforma criada para jovens de 15 e 16 anos interessados em cultura, criatividade e descobertas. Aqui você explora temas do dia a dia e compartilha novas ideias.

Missão

Valorizar os interesses dos jovens e estimular a curiosidade.

Tecnologias

HTML para a estrutura, CSS para o visual e JavaScript para as interações.

Recursos

Menu responsivo, filtros, mosaico de imagens e modal com navegação.
